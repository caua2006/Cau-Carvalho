O que é NFC?\n\nNFC (Near Field Communication) é uma tecnologia de comunicação por aproximação que permite a troca de informações entre dispositivos sem fio. No Tap On PagBank, ela é usada para aceitar pagamentos apenas aproximando cartões, celulares ou dispositivos compatíveis.\n\n### 4.
